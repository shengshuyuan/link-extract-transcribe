# 微信文章提取

仅用于用户有权处理的公开文章。不保证任意链接可读，遇到验证或没有正文时会停止。

```sh
~/.workbuddy/venvs/link-extract/bin/python "/技能实际安装路径/scripts/wxfetch.py" "https://mp.weixin.qq.com/s/文章ID" "00-inbox/提取临时/一个尚不存在的目录"
```

命令中的Python是默认专用环境；其他安装位置以setup_web.py输出为准。脚本位置通过 WorkBuddy 的技能安装信息查找，不把这里的示意路径直接运行。`outdir` 必须不存在。图片可加 `--download-images`，按 URL 去重，每次最多尝试 20 张、累计成功下载不超过 32 MiB；超限保留远程链接并记录原因。图片下载失败会记录在 `article.json`，正文保留远程图片链接并报告该问题，不能称图片已离线保存。

输出 `article.md`、`article.json` 和可选 `images/`。发布时间固定 UTC+08:00，无法取到时留空，不编造。元数据经过字符串转义。`scope` 提醒正文完整性仍需核对，存在正文不等于付费段落、图片文字或外链内容都已经读取。

依赖：`requirements-web.txt`。只有确认需要该脚本时，才在独立虚拟环境安装依赖；无需同时安装语音模型。

脚本只请求微信文章和指定微信图片域名，逐次检查跳转、状态、大小和图片类型；已有输出目录会停止。遇到验证、删除、登录或无正文，停止并请用户提供正文/导出文件，不换IP或提取浏览器cookie规避限制。

脚本先写到当前Vault的临时目录，检查无误后按材料ID归档到 `10-sources/`。不要直接把这次提取覆盖到已有笔记目录；需要复制图片时保持 Markdown 中相对路径一致。
