# 个人知识库示例

复制本文件夹到自己的文档目录，用 Obsidian 打开它，并在 WorkBuddy 选择同一个文件夹作为工作目录。不要把整个代码仓库当作 Vault。

每次任务先读知识库规则、分类规则、材料索引和模板。`00-inbox` 放待整理材料，`10-sources` 放来源，`20-wiki` 放分类笔记，`30-assets` 放附件，`90-templates` 放模板。

默认 `preview`，先看草稿再保存。用户明确要求本次保存可新增；长期自动新增需明确授权，并同时更新配置和知识库规则。旧文件不覆盖，索引只追加。

这里没有真实文章或私人笔记。可以将上一级 `practice.txt` 或 `sample.srt` 复制到 `00-inbox` 做离线练习。
